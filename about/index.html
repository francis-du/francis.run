    About

    我是 Francis Du，做数据工程，也在做 Agent / Data Agent 相关开发，平时写 Rust、折腾开源项目，也喜欢摄影。

    这些年主要和数据平台、分布式系统、查询引擎打交道。现在也在持续做一个私有 Data Agent 项目，积累了不少 Agent 工程和评估方面的经验。

    业余时间主要维护 wcode。之前也参与过 Apache DataFusion 和 DataFusion Python 的开源贡献。

    🛠️ 我在做什么

    • 数据工程 · Data Engineering — 主要做数据平台、分布式系统和查询引擎相关的工程工作。
    • Agent / Data Agent — 有 Agent 开发和评估经验，目前也在持续开发一个私有 Data Agent 项目，主要关注数据检索、工具调用、任务编排和可靠性。
    • Rust · wcode — wcode 是我现在主要维护的开源项目，一套面向 Coding Agent 的本地 runtime / harness。
    • 开源 · Open Source — 参与过 Apache DataFusion 和 DataFusion Python 的开源贡献，其他项目和实验放在 GitHub。
    • 摄影 · Photography — 用镜头记录旅途与日常，作品收在本站的 相册 里。
