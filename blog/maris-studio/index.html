Maris：把电脑的声音调成自己喜欢的样子

3 分钟阅读1458 字

Maris 是一个系统级音频工具。它处理电脑上正在播放的声音，让你给耳机、音箱保存不同的设置，做耳机校正，调低音、高音、立体声宽度和动态范围。

播放器里的均衡器只管那个播放器。换到浏览器看视频，换个应用听歌，往往还要再配一次。Maris 放在系统音频这一层，同一套设备设置可以用于不同应用。换耳机或音箱时，也有各自的配置可以选。

我想做的是这样一件日常工具：喜欢的声音调好一次，以后用起来省点事；需要细调的时候，又能看清正在改什么。

先照顾好耳机和音箱#

同一首歌，换一副耳机听，低频、人声和空间感都可能变。音箱又有音箱自己的特点，直接套同一套参数通常不太合适。

Maris 把设备校正和个人听音偏好分开处理。

耳机校正使用 AutoEq 的参数配置。找到对应型号后，可以按这份配置调整频段。这里的依据来自已有测量；Maris 不会戴上耳机替你测一遍，也不能推断你的佩戴和房间声学。

在校正之上，再调整自己想听的声音：低音多一点，人声更突出一点，或者收一收太刺激的高频。参数可以保存到对应设备，下次继续用。

这比只给一个“增强”按钮更合我的想法。我希望能把变化拆开听，也能随时回到之前的设置。

调的时候，看得见，也听得出来#

当前 TUI 使用生成的测试音频渲染，展示界面和控制布局。

Maris 现在有终端工作台和原生菜单栏入口。主界面会显示当前输出、校正配置、频谱、EQ 曲线和左右声道电平，常用参数放在旁边。

假设你觉得某副耳机低频偏少，可以选中低音参数，用加减键逐步调，再按 B 做参考对比。喜欢就保留，不喜欢用 U 撤销。进入设置页做一组修改时，先改草稿，确认后再应用。

EQ 曲线显示的是当前处理设置的变化，频谱显示输入声音里各频段的能量。两张图各有用处：前者帮你知道自己动了哪里，后者帮你观察正在播放什么。最后还是要听。

除了均衡，Maris 还有动态频段处理、压缩、可选的虚拟低音和立体声宽度调整。比如声音忽大忽小，可以试着收一点动态；小设备的低频表现有限，也可以尝试虚拟低音。效果要结合设备和内容判断，不需要把所有处理都打开。

菜单栏适合快速选输出、切场景和停止处理，终端工作台适合把参数摊开慢慢调。两边共用设置，保存后还会区分等待生效和已被音频线程应用的状态。

不同应用，也能分开管#

普通使用可以先从一个输出设备开始。需要更细的路由时，Maris 还有混音器。

它可以把多个应用或音频输入作为独立声道，分别调音量、声像、静音、独奏、EQ 和压缩，再送到两路独立输出。

比如耳机和音箱同时接着，希望音乐走一边、另一个应用走另一边，可以按声道安排。也可以只处理选中的应用，其他应用保持自己的路径。应用音频能怎样选择、路由切换后怎样恢复，要看各平台后端的支持。

目前 macOS 14.2 及以后走 CoreAudio 系统音频捕获，Windows 走 WASAPI，Linux 接本地 PulseAudio，也包括 PipeWire 的 PulseAudio 兼容层。这些是各平台的原生接入方式，具体设备兼容性还要逐项验证。

分析在本地，播放照常进行#

Maris 也接了本地 MusicNN，可以提供曲风、乐器一类的分析信息，作为调音时的参考。识别需要相应模型权重；没有模型或识别不出来时，普通播放和声音处理仍然可用。

音频分析在本地运行，不需要把原始音频发给云端识别服务。语音降噪也可以单独开启，用在需要它的声道上。

如果想做自动化，还有 JSON 命令行和 MCP。程序可以读取状态，获得修改权限后调整设置，使用和界面相同的检查与撤销。这样也能把 Maris 接到自己的脚本或 Agent 工作流里。

Maris 还在开发中，暂时没有公开应用安装包。源码、当前能力和使用文档都在 GitHub。我会继续把设备切换、菜单栏和听音操作做好，再把各平台的实际使用打磨完整。
